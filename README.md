## Agentic SEO Skill Setup

The [Agentic-SEO-Skill](https://github.com/Bhanunamikaze/Agentic-SEO-Skill) has been installed for Claude Code.

### Installation

```bash
git clone https://github.com/Bhanunamikaze/Agentic-SEO-Skill.git
cd Agentic-SEO-Skill
bash install.sh --target claude
```

Installs to: `~/.claude/skills/seo`

Restart your Claude Code session to pick up the skill.
